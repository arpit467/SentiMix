⚙️ Code-Mixed NLP Preprocessing Pipeline

1. Phonetic Normalization:

Maps informal transliteration spelling noise (e.g. achha, acha → accha; bhut, bhot → bahut; bekaar → bekar).

2. Demojization & Emoji Vectors:

Converts unicode emojis into descriptive semantic tokens (e.g. :thumbs_up:, :disappointed_face:) to retain emotional polarity.

3. Adversative Clause Splitting:

Segments compound code-mixed reviews around contrastive markers (par, lekin, but, halanki) so conflicting aspect polarities don't interfere.

🧠 Model Architectures & Technical Specifications

Detailed architecture breakdown, embedding representations, and algorithmic formulations for all 6 benchmarked ABSA models.

Technical Specs
71.25% Acc • 0.29ms

⚡ TF-IDF + Logistic Regression

Production-grade classical ML combining dual-level Word & Character N-Grams with calibrated multinomial logistic regression.

  • Feature Representation: Word $(1,3)$ n-grams + Sublinear Character $(2,5)$ n-grams.
  • Regularization: $L_2$ penalty ($C=1.0$), balanced class weighting.
  • Strengths: Subword character n-grams match noisy transliterations without out-of-vocabulary token fragmentation.
  • Production Latency: 0.29 ms (220x faster than transformers).
63.25% Acc • 110M

🇮🇳 IndicBERT (ai4bharat)

Indian language multilingual transformer pre-trained on 12 major Indian languages + Romanized Hindi.

  • Base Model: ai4bharat/IndicBERTv2-MLM-only (Albert architecture).
  • Sentence Pair: [CLS] Clause Context [SEP] Aspect Term [SEP].
  • Strengths: Native understanding of Devanagari and phonetic Romanized Hindi structures.
  • Latency: 66.70 ms / sample.
63.00% Acc • 117M

🌐 Multilingual MiniLM

High-throughput cross-lingual dense semantic embedding model designed for sub-millisecond semantic representation.

  • Base Model: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2.
  • Embedding Dim: 384-dimensional dense contextual pooling.
  • Strengths: Fast cross-lingual transfer, compact model footprint (470 MB).
  • Latency: 32.46 ms / sample.
57.12% Acc • 278M

🤖 XLM-RoBERTa

Massive cross-lingual masked language model pre-trained on 2.5TB of CommonCrawl data across 100+ languages.

  • Base Model: xlm-roberta-base (278M parameters).
  • Embedding Dim: 768-dimensional contextual representations.
  • Limitation: Transliterated Hinglish creates subword fragmentation on non-phonetic tokens.
  • Latency: 89.16 ms / sample.
40.62% Acc • 236M

🔤 MuRIL (Google)

Multilingual Representations for Indian Languages trained on both native scripts and transliterated Indian texts.

  • Base Model: google/muril-base-cased (236M parameters).
  • Target: Specifically pre-trained on Romanized and transliterated Hindi pairs.
  • Latency: 63.31 ms / sample.
40.89% Acc • 0.16ms

📐 Syntactic Rule-Based Lexicon

Interpretable rule engine computing polarity via syntactic proximity windows, negation words, and clause boundaries.

  • Heuristics: $\pm 4$ token window around aspect terms, Hindi sentiment lexicon.
  • Negation Handling: Inverts polarity when markers (nahi, mat, na) precede aspect.
  • Role: Serves as an ultra-fast zero-shot baseline and fallback.
  • Latency: 0.16 ms / sample.
