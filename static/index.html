📋 Phase 2 Evaluation Rubric & Scientific Viva Guide

Formal presentation of all research methodologies, feature engineering techniques, and architectural decisions.

Technical Viva
5% Weight

1. Code-Mixed Feature Engineering

  • Transliteration Spelling Normalization: Canonicalizing phonetic spelling noise (achha, accha → accha; bhut, bhot → bahut).
  • Demojization & Sentiment Preservation: Extracting unicode emoji sentiment tokens (e.g. :sparkles:, :disappointed_face:).
  • Dual-Level TF-IDF Vectors: Combining Word $(1,3)$ n-grams with Sublinear Character $(2,5)$ n-grams for subword stem matching.
  • Clause Boundary Decomposition: Splitting compound reviews around adversative markers (par, lekin, but, halanki).
8% Weight

2. Multi-Model Architecture Implementation

  • Model 1 (Baseline): Syntactic Proximity Lexicon Rule Engine.
  • Model 2 (Production ML): TF-IDF + Multinomial Logistic Regression ($L_2$ regularization, balanced class weights).
  • Model 3 (Indic Transformer): IndicBERT (ai4bharat/IndicBERTv2-MLM-only, 110M params).
  • Model 4 (Cross-Lingual): XLM-RoBERTa (xlm-roberta-base, 278M params).
  • Model 5 (Transliteration BERT): MuRIL (google/muril-base-cased, 236M params).
5% Weight

3. Experimental Benchmark Protocol

  • Master Ingestion: 12,604 aspect pairs across 5 e-commerce and benchmark domains.
  • Isolated Hinglish Evaluation: 93.4% code-mixed test partition evaluated independently.
  • Scientific Metrics: Accuracy, Macro Precision/Recall, Macro/Weighted F1, Hinglish F1, and Latency (ms).
4% Weight

4. Key Scientific Insights

  • Why TF-IDF Leads (72.6% Acc): Character n-grams match noisy transliterations without suffering from out-of-vocabulary subword token fragmentation.
  • IndicBERT Advantage: IndicBERT (63.3%) outperforms generic XLM-RoBERTa (57.1%) due to Indian phonetic pre-training.
  • Latency Supremacy: TF-IDF delivers 0.29 ms latency (over 220x faster than deep neural models), making it the ideal production deployment choice.
